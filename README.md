# Web Portfolio Fullstack (PHP Native & MySQL)

Proyek web portofolio profesional yang dibangun menggunakan **PHP Native** dan **MySQL**, dilengkapi dengan sistem manajemen basis data, antarmuka responsif berbasis **Bootstrap 5**, serta fitur pengiriman pesan/notifikasi otomatis menggunakan **PHPMailer (SMTP Gmail)**.

## 🚀 Fitur Utama
* **Halaman Portofolio Dinamis**: Menampilkan profil, riwayat proyek, dan keahlian secara interaktif.
* **Formulir Kontak Otomatis**: Terintegrasi langsung dengan **PHPMailer** menggunakan protokol SMTP Gmail untuk mengirim pesan langsung ke email pengembang.
* **Manajemen Basis Data**: Struktur relasional SQL yang bersih dan terstandarisasi untuk pengelolaan data portofolio.
* **Keamanan Kredensial**: Pemisahan konfigurasi sensitif menggunakan templat aman agar informasi privat tidak terekspos ke publik.

## 🛠️ Teknologi yang Digunakan
* **Bahasa Pemrograman**: PHP (Native)
* **Basis Data**: MySQL (XAMPP Server)
* **Frontend**: Bootstrap 5, HTML5, CSS3, JavaScript
* **Library/Dependencies**: PHPMailer (via Composer)
